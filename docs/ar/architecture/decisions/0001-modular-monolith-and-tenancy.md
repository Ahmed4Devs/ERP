# قرار معماري رقم 0001: معمارية الكتلة الموديلارية وتعدد المستأجرين الهيكلي

## الحالة
مقبول ومُعتمد (Accepted)

## السياق (Context)
يتطلب نظام تخطيط موارد المؤسسات (ERP) عزلاً صارماً بين المنظمات المستفيدة (المستأجرين)، مع دعم الشركات القانونية والفروع المتعددة لكل مستأجر، وضمان الصحة المالية المطلقة وتسهيل الصيانة دون تعقيد تشغيلي موزع غير مبرر.

## القرار (Decision)
1. اعتماد هيكل **الكتلة الموديلارية (Modular Monolith)** داخل Laravel تحت `app/Modules/` و `app/Shared/`.
2. اعتماد **قاعدة بيانات مشتركة مع عزل هيكلي صريح** عبر المفاتيح (`tenant_id`, `company_id`, `branch_id`).
3. استخراج وتأكيد سياق المستأجر والشركة النشطة بناءً على العضوية المعتمدة للمستخدم المسجل في كل طلب عبر برمجية وسيطة `EnsureTenantAndCompanyScope`.
4. الواجهة الأمامية: React 19 SPA متصلة عبر Inertia.js مع TypeScript و Tailwind v4.

## التبعات والنتائج (Consequences)
- قاعدة البيانات العلائقية الواحدة تتيح معاملات ذرية (Atomic Transactions) تضمن التوازن المحاسبي بين دفاتر الأستاذ واليومية.
- انعدام تأخيرات الشبكة وتعقيدات التنسيق الموزع للميكروسيرفسز.
- وجوب تطبيق سمات العزل الصارمة على كافة النماذج والاستعلامات.
