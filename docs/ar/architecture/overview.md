# النظرة العامة على المعمارية (Architecture Overview)

## 1. الهيكل المعماري الأحادي الموديلاري (Modular Monolith)
تم بناء النظام وفق معمارية الكتلة الموحدة المجزأة موديولارياً (Modular Monolith) داخل تطبيق Laravel واحد، متصلاً بواجهة React 19 عبر Inertia.js، ومستنداً إلى قاعدة بيانات PostgreSQL 18 واحدة.

### الطبقات المعمارية الرئيسية:
1. **الأساسيات المشتركة (`app/Shared`)**: سمات النطاق المشتركة (`BelongsToTenant`, `BelongsToCompany`)، كائنات القيمة المالية (Money Value Object)، وسياق التنفيذ وعقود التدقيق.
2. **موديول المنصة (`app/Modules/Platform`)**: إدارة المستأجرين (Tenants)، المستخدمين، المصادقة، التحقق الثنائي (MFA)، الأدوار والصلاحيات (RBAC)، ونظام التدقيق المركزي.
3. **موديول التنظيم والمؤسسات (`app/Modules/Organization`)**: إدارة الكيانات القانونية (الشركات)، الفروع، الأقسام، ومراكز التكلفة.
4. **موديول البيانات الأساسية (`app/Modules/MasterData`)**: الأطراف (العملاء والموردين)، المنتجات والخدمات، الوحدات، الرموز الضريبية، وقوائم الأسعار.
5. **موديولات الأعمال المتخصصة**: الحسابات والمالية، المبيعات، المشتريات، المخزون، الموارد البشرية، والرواتب.

## 2. العزل الهيكلي وتعدد المستأجرين والشركات
- **نموذج قاعدة البيانات**: قاعدة بيانات PostgreSQL مشتركة مع عزل صريح على مستوى المستأجر والشركة.
- **المستأجر (Tenant)**: الكيان المنظم المستقل الحاكم للحساب. تحوي كافة الجداول ذات الصلة المفتاح الخارجي `tenant_id`.
- **الشركة (Company)**: الشخصية الاعتبارية القانونية داخل المستأجر. السجلات المالية والمحاسبية والفواتير والمخزون ترتبط صراحة بالمعرف `company_id`.
- **الفرع (Branch)**: الموقع التشغيلي التابع للشركة ويحمل `branch_id`.
- **ضمانات العزل**: يتم فرض نطاق العزل بنيوياً عبر سمات الموديل (Model Traits)، طلبات التحقق (Form Requests)، ربط المسارات بالنماذج (Route Model Binding)، وسياسات الصلاحيات (Policies). لا يُكتفى بالنطاقات العامة (Global Scopes) كحد أمني وحيد.
