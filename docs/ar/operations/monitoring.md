# دليل المراقبة وفحص السلامة والجاهزية التشغيلية

يوضح هذا الدليل آليات فحص سلامة التطبيق، ومراقبة معالجات المهام، وسجلات التتبع الهيكلية، ومؤشرات الأداء التشغيلي لنظام تخطيط الموارد المؤسسية (ERP).

---

## 1. فحص سلامة التطبيق (Health Checks)

يوفر إطار العمل نقطة نهاية خفيفة وسريعة لفحص سلامة النظام عبر المسار `/up`.

### المسار: `GET /up`
- **الاستجابة**: كود الحالة HTTP 200 OK.
- **حالات الاستخدام**: فحوصات موزعات الأحمال (Load Balancers)، وفحوصات الجاهزية في Kubernetes، وأنظمة مراقبة التوفر (مثل Datadog و BetterStack).
- **الأمان**: لا تفصح الاستجابة عن أي بيانات اعتماد أو أسرار تقنية تخص قاعدة البيانات.

---

## 2. مراقبة طوابير الانتظار ومعالجات الخلفية

تتم إدارة المهام الخلفية (الإشعارات، تقارير المحاسبة، والفواتير الدورية المجدولة) عبر طوابير PostgreSQL أو Redis.

### الأوامر التشغيلية عبر سطر الأوامر:
```bash
# مراقبة حجم طابور المهام النشط
php artisan queue:monitor default --max=100

# استعراض المهام المتعثرة أو التي واجهت أخطاء
php artisan queue:failed

# إعادة محاولة تنفيذ كافة المهام المتعثرة بعد حل المشكلة
php artisan queue:retry all

# تنظيف سجلات المهام المتعثرة القديمة
php artisan queue:prune-failed --hours=72
```

## 3. سجلات التتبع الهيكلية ومعرّفات الارتباط (Correlation IDs)

تعتمد سجلات الإنتاج على تنسيق JSON الهيكلي لتسهيل فهرستها والبحث فيها عبر منصات السجلات المركزية (OpenSearch, ELK, Grafana Loki).

### مخطط سجل الأحداث:
```json
{
  "timestamp": "2026-09-11T14:15:30.123456Z",
  "level": "INFO",
  "message": "POS Sale completed and balanced journal posted.",
  "context": {
    "tenant_id": "01a090d3-a1e6-7347-87a2-bf9f764f715c",
    "company_id": "01a090d3-a1e9-733d-a75e-a2a5fc976ef3",
    "user_id": 14,
    "terminal_id": "01a090d3-a1fa-7890-bcde-fa1234567890",
    "receipt_number": "POS-REC-202609-0012",
    "total_amount": "1650.000000",
    "ip_address": "192.168.1.100"
  }
}
```

### حجب وتشفير البيانات الحساسة:
يتم تلقائياً حجب البيانات التالية من كافة السجلات:
- كلمات المرور (`password`, `password_confirmation`).
- مفاتيح الواجهات البرمجية والرموز السرية (`token`, `secret`, `api_key`).
- تفاصيل البطاقات الائتمانية والمدفوعات.

## 4. مستويات الخدمة ومؤشرات زمن الاستجابة (SLA & SLO)

| العملية | المعدل الوسيط (p50) | الشريحة 95% (p95) | أقصى زمن (p99) |
|---|---|---|---|
| **مسح الباركود وتحديث السلة في الكاشير** | < 30 مللي ثانية | < 80 مللي ثانية | < 150 مللي ثانية |
| **إتمام الدفع في نقاط البيع وترحيل القيد** | < 100 مللي ثانية | < 250 مللي ثانية | < 500 مللي ثانية |
| **اعتماد عروض الأسعار وأوامر البيع** | < 80 مللي ثانية | < 200 مللي ثانية | < 400 مللي ثانية |
| **تسجيل حركة المخزون وإعادة التقييم** | < 90 مللي ثانية | < 220 مللي ثانية | < 450 مللي ثانية |
| **استخراج ميزان المراجعة والتقارير المالية** | < 150 مللي ثانية | < 350 مللي ثانية | < 800 مللي ثانية |
