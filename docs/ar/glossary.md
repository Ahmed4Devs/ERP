# مسرد المصطلحات المعيارية (Glossary)

| المصطلح العربي | المصطلح الإنجليزي | التعريف والشرح |
|---|---|---|
| مستأجر / منظمة عميل | Tenant | النطاق الأعلى للمؤسسة الحاكمة، يمثل منظمة مستقلة أو مجموعة شركات تجارية. |
| شركة / كيان قانوني | Company | الشخصية الاعتبارية القانونية التابعة للمستأجر، ذات رقم ضريبي مستقل وعملة ودفاتر محاسبية مستقلة. |
| فرع / موقع تشغيلي | Branch | موقع فيزيائي أو مكتب أو متجر أو مستودع تابع لشركة محددة. |
| عضوية | Membership | الربط الصريح بين المستخدم والمستأجر مع تحديد نطاق الأدوار والشركة الافتراضية. |
| التحكم بالوصول المستند إلى الأدوار | Role-Based Access Control (RBAC) | نموذج أمني تُجمع فيه الصلاحيات ضمن أدوار وتُسند إلى عضويات المستخدمين. |
| التحقق متعدد العوامل | Multi-Factor Authentication (MFA) | آلية أمنية تلزم التحقق من عاملي هوية على الأقل قبل السماح بالدخول للأدوار الحساسة. |
| سجل التدقيق | Audit Log | سجل غير قابل للتعديل يوثق بدقة الفاعل والإجراء والكيان والوقت والـ IP. |
| طرف تجاري | Party | كيان موحد يمثل العميل أو المورد أو الشريك التجاري على مستوى المستأجر. |
| دفتر الأستاذ العام | General Ledger | السجل الجامع لكافة الحسابات المالية والقيود المحاسبية المرحلة المتوازنة. |
| قيد اليومية | Journal Entry | سجل محاسبي متوازن يتألف من أسطر دائنة ومدينة بعملة الأساس الخاصة بالشركة. |
