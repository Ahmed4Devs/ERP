# خارطة طريق تنفيذ المنتج (Roadmap)

| المرحلة | نطاق العمل | المخرجات الرئيسية | الحالة |
|---|---|---|---|
| M0 — الفحص والتوصيف المعماري | فحص بيئة العمل، نموذج التهديدات، القرارات المعمارية، مخطط الكيانات، التوثيق المزدوج | سجل توافق التقنيات، ADR-0001، خط أساس ASVS، هيكل التوثيق | مكتمل (Complete) |
| M1 — الأساس المنصي وتعدد المستأجرين | المصادقة، التحقق الثنائي (MFA)، المستأجرين والشركات والفروع، الصلاحيات، الواجهة ثنائية اللغة، اختبارات العزل | تسجيل الدخول، مبدل الشركات، إدارة الأطراف، اختبارات Pest السلبية | قيد التنفيذ (In Progress) |
| M2 — الحسابات وإيرادات الخدمات | دليل الحسابات، الفترات المالية، محرك الترحيل المتناهي الدقة، فواتير الخدمات وسندات القبض، ميزان المراجعة | دورة فوترة الخدمات، القيود المتوازنة، التوليد والطباعة بالعربية والإنجليزية | مخطط (Planned) |
| M3 — المشتريات والتحكم بالنقد | أوامر الشراء، فواتير الموردين، الذمم الدائنة، سندات الصرف، المصروفات، التسويات البنكية | سجل الموردين، المطابقة الثلاثية، تسوية البنك | مخطط (Planned) |
| M4 — المخزون والتوزيع | المنتجات، الوحدات، المستودعات، حركات المخزون، التقييم بالمتوسط المرجح، مطابقة البضائع غير المفوترة | سجل المخزون، تكلفة البضاعة المباعة (COGS)، منع الرصيد السالب | مخطط (Planned) |
| M5 — إدارة القوى العاملة والأصول | الموارد البشرية، الحضور، إطار الرواتب، سجل الأصول الثابتة، الإهلاك، الموازنات، الإقفال المالي | سجل الأصول، قيود الإهلاك، إعداد الرواتب | مخطط (Planned) |
| M6 — إدارة العمليات والخدمات التجارية | إدارة علاقات العملاء (CRM)، عروض الأسعار، تتبع المشاريع وأوقات العمل، العقود الدورية، التذاكر | ربحية المشاريع، الفوترة المتكررة للعقود | مخطط (Planned) |
| M7 — الحزم القطاعية والتكاملات | التوزيع وتجارة الجملة، نقاط البيع بالتجزئة (POS)، المقاولات، التصنيع الخفيف، التوطين الضريبي | ميزات الصناعات المحددة وفق الطلب | مخطط (Planned) |
| M8 — التحقق الشامل للإصدار | اختبارات الانحدار، مراجعة ASVS الأمنية، تمارين الاستعادة والنسخ الاحتياطي، إمكانية الوصول، تصدير التوثيق | الجاهزية التشغيلية للإنتاج | مخطط (Planned) |
