# خارطة طريق تنفيذ المنتج (Roadmap)

| المرحلة | نطاق العمل | المخرجات الرئيسية | الحالة |
|---|---|---|---|
| M0 — الفحص والتوصيف المعماري | فحص بيئة العمل، نموذج التهديدات، القرارات المعمارية، مخطط الكيانات، التوثيق المزدوج | سجل توافق التقنيات، ADR-0001، خط أساس ASVS، هيكل التوثيق | مكتمل (Complete) |
| M1 — الأساس المنصي وتعدد المستأجرين | المصادقة، التحقق الثنائي (MFA)، المستأجرين والشركات والفروع، الصلاحيات، الواجهة ثنائية اللغة، اختبارات العزل | تسجيل الدخول، مبدل الشركات، إدارة الأطراف، اختبارات Pest السلبية | مكتمل (Complete) |
| M2 — الحسابات وإيرادات الخدمات | دليل الحسابات، الفترات المالية، محرك الترحيل المتناهي الدقة، فواتير الخدمات وسندات القبض، ميزان المراجعة | دورة فوترة الخدمات، القيود المتوازنة، التوليد والطباعة بالعربية والإنجليزية | مكتمل (Complete) |
| M3 — المشتريات والتحكم بالنقد | أوامر الشراء، فواتير الموردين، الذمم الدائنة، سندات الصرف، المصروفات، التحويلات النقدية | ملفات الموردين، دورة اعتماد أمر الشراء، فواتير الموردين مع ضريبة المدخلات 10%، صرف وتخصيص الدفعات، تحويلات الخزينة، تقرير أعمار ديون الموردين | مكتمل (Complete) |
| M4 — المخزون والتوزيع | المنتجات، الوحدات، المستودعات، حركات المخزون، التقييم بالمتوسط المرجح، منع المخزون السالب، مطابقة وتسوية GRNI، المناقلات، التسويات الجردية | محرك تقييم المتوسط المرجح، سندات استلام البضائع مع وسيط GRNI، مناقلات المستودعات، تسويات المخزون، تقرير تقييم المخزون المالي والمطابقة مع حساب 1300 | مكتمل (Complete) |
| M5 — إدارة القوى العاملة والأصول | الموارد البشرية، الحضور، إطار الرواتب، سجل الأصول الثابتة، الإهلاك، الموازنات، الإقفال المالي | ملفات الموظفين، مسيرات الرواتب الشهرية والترحيل المزدوج لـ GL والصرف البنكي، سجل الأصول الثابتة ومحرك الإهلاك بالقسط الثابت، إقفال الفترات المالية | مكتمل (Complete) |
| M6 — إدارة العمليات والخدمات التجارية | إدارة علاقات العملاء (CRM)، عروض الأسعار، تتبع المشاريع وأوقات العمل، العقود الدورية، التذاكر | تحويل الفرص، عروض وأوامر البيع، ربحية المشاريع، الفوترة المتكررة للعقود، تذاكر الدعم الفني | مكتمل (Complete) |
| M7 — الحزم القطاعية والتكاملات المتقدمة | التوزيع وتجارة الجملة، نقاط البيع بالتجزئة (POS)، المقاولات، التصنيع الخفيف، التوطين الضريبي | شاشة كاشير POS تفاعلية مع حسم المخزون اللحظي وترميز ZATCA QR، هياكل المواد وأوامر التجميع، تسعير الجملة بالشرائح، مستخلصات المقاولات وخصم 5% ضمان | مكتمل (Complete) |
| M8 — التحقق الشامل للإصدار | اختبارات الانحدار، مراجعة ASVS الأمنية، تمارين الاستعادة والنسخ الاحتياطي، إمكانية الوصول، تصدير التوثيق | الجاهزية التشغيلية للإنتاج | مخطط (Planned) |
