# مصفوفة الأدوار والصلاحيات (RBAC Matrix)

## 1. هيكل تسمية الصلاحيات
تتبع الصلاحيات نمطاً معيارياً موحداً: `{module}.{resource}.{action}`
أمثلة:
- `platform.tenant.manage` (إدارة إعدادات المستأجر)
- `organization.company.view` (استعراض بيانات الشركة)
- `organization.company.create` (إنشاء شركة تابعة)
- `organization.branch.manage` (إدارة الفروع)
- `masterdata.party.view` (استعراض ملفات الأطراف والعملاء)
- `masterdata.party.create` (إنشاء طرف/عميل جديد)
- `masterdata.party.update` (تحديث بيانات طرف/عميل)
- `accounting.invoice.view` (استعراض الفواتير)
- `accounting.invoice.post` (ترحيل الفاتورة محاسبياً)

## 2. الأدوار القياسية المعتمدة
1. **مدير المستأجر الأعلى (Tenant Super Admin)**: إدارة شاملة للمستأجر، الشركات، الفروع، والمستخدمين.
2. **مدير الشركة (Company Administrator)**: إدارة الإعدادات والبيانات الأساسية وتعيين صلاحيات موظفي الشركة القانونية.
3. **المراقب المالي / المحاسب (Financial Controller / Accountant)**: إدارة القيود المحاسبية، محرك الترحيل، الحسابات البنكية. يلزم التحقق بخطوتين (MFA).
4. **مسؤول العمليات / المبيعات (Sales & Operations Officer)**: إنشاء عروض الأسعار، أوامر البيع، إدارة العملاء وسندات التسليم.
5. **مدقق / قراءة فقط (Auditor / Read-Only)**: استعراض السجلات المحاسبية والتقارير ضمن النطاق المصرح دون حق التعديل.
