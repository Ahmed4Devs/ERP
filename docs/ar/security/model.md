# نموذج التهديدات والضوابط الأمنية (OWASP ASVS 5.0.0)

## 1. المعيار الأمني وخط الأساس
يتبنى النظام معيار التحقق من أمان التطبيقات OWASP ASVS الإصدار 5.0.0، مستهدفاً كافة ضوابط المستوى الثالث (Level 3) القابلة للتطبيق للبيانات المالية والمؤسسية الحساسة، مع اعتبار ضوابط المستويين الأول والثاني (Level 1 & 2) خط أساس إلزامي.

## 2. تحليل التهديدات وإجراءات التخفيف

| متجه التهديد (Threat) | الأثر المحتمل | المعالجة والضوابط المعمارية |
|---|---|---|
| اختراق نطاق المستأجر (Tenant Escape) | وصول غير مصرح لبيانات عميل آخر | المفاتيح الأجنبية المركبة، عزل استعلامات المستأجر، تحقق البرمجية الوسيطة وسياسات التخويل |
| التسلل بين الشركات (Horizontal Company Escalation) | تعديل سجلات شركة أخرى داخل المستأجر | فرض سياق الشركة الصريح على كافة عمليات الإدخال والتعديل مع سياسات عزل دقيقة |
| التلاعب بالاعتمادات والقيود المالية | تغيير مستندات معتمدة أو قيود مرحلة | ثبات القيود المرحلة (Immutability)، فصل مراحل الاعتماد، وسجلات تدقيق كاملة |
| الاستيلاء على الحسابات (Account Takeover) | اختراق حسابات المسؤولين والمخولين مالياً | إلزام التحقق الثنائي (MFA/TOTP/Passkeys) للأدوار الإدارية والمالية الحساسة |
| هجمات الحقن (Injection Attacks) | حقن استعلامات SQL أو برمجيات خبيثة | استعلامات Eloquent المحمية، تحييد مدخلات React JSX التلقائي، والتحقق الصارم عبر Form Requests |
| تسريب البيانات عبر التصدير | سحب كميات ضخمة من البيانات غير المصرح بها | تقييد عمليات التصدير بالصلاحيات، تسجيل التنزيلات في سجل التدقيق، وتطبيق حدود التردد (Throttling) |
