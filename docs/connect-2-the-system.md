1. تشغيل خادم التطوير (Local Dev Server)
افتح سطر الأوامر (Terminal)

```powershell
composer run dev
```

```
أو تشغيلهما في نافذتين منفصلتين:
النافذة الأولى (خادم PHP): 
php artisan serve
النافذة الثانية (مترجم الواجهة والتحديث الحي Vite): 
npm run dev
```
